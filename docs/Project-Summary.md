# Project Summary

## Objective

Design and implement a secure Azure AI platform using Azure AI Foundry, Azure API Management, Microsoft Entra ID, Azure Key Vault, Private Endpoints, Private DNS, and Microsoft Sentinel.

## Security Controls Implemented

- JWT Authentication
- Prompt Injection Protection
- Sensitive Data Protection
- Managed Identity
- Key Vault Integration
- Private Endpoint Connectivity
- Log Analytics Monitoring
- Sentinel Integration

## Security Validation

Validated using:

- Prompt Injection Testing
- System Prompt Extraction Testing
- JWT Authentication Testing
- DLP Testing

## Technologies

- Azure AI Foundry
- Azure API Management
- Microsoft Entra ID
- Azure Key Vault
- Private DNS
- Private Endpoints
- Log Analytics
- Microsoft Sentinel

## Outcome

Successfully implemented an enterprise AI Security Gateway with preventive, detective, and monitoring controls.
